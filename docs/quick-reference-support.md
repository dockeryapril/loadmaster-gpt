## 🚨 Emergency Issues (Immediate Help)

### Can't Sign In
1. **Reset password:** "Forgot Password" on login page
2. **Check email:** Look in spam folder for reset email  
3. **Try different browser:** Chrome works best
4. **Clear cache:** Browser settings → Clear data

### OCR Upload Failed
1. **Check upload limit:** Free=4/week, Pro=100/week
2. **Try manual entry:** Always unlimited
3. **Smaller image:** Compress if over 10MB
4. **Different format:** Try PNG if JPG fails

### Payment/Billing Issues
1. **Check payment method:** Update expired cards
2. **Contact support:** Include "BILLING" in subject
3. **Stripe issues:** Usually resolve within 24hrs
4. **Cancellation:** Account Settings → Billing

## 🔍 Self-Diagnosis Checklist

### Before Contacting Support
- [ ] **Clear browser cache** - Fixes 30% of issues
- [ ] **Try different browser** - Chrome recommended
- [ ] **Check internet connection** - Test other websites
- [ ] **Restart device** - Mobile users especially
- [ ] **Review recent changes** - New password, settings, etc.

### Information to Gather
- [ ] **Exact error message** - Copy/paste or screenshot
- [ ] **Browser and version** - Chrome 90+, Safari 14+
- [ ] **Device type** - iPhone 12, Windows 10, etc.
- [ ] **Steps to reproduce** - What did you do before error?
- [ ] **Frequency** - One-time or recurring?

## 🔧 Quick Fixes by Problem Type

### OCR Problems (40% of tickets)

**Low Accuracy**
```
✅ Immediate Fixes:
• Better lighting when taking screenshot
• Crop image tighter (load info only)  
• Use manual correction (click Edit)
• Try PNG format instead of JPG

⚠️ Contact Support If:
• Same error on multiple different images
• OCR returns completely blank results
• Processing takes over 2 minutes
```

**Upload Limit Reached**
```
✅ Immediate Fixes:
• Check counter on dashboard (Free: 4/week)
• Use manual entry (unlimited)
• Upgrade to Pro (100/week)
• Wait for Sunday reset

⚠️ Contact Support If:
• Counter shows wrong number
• Just upgraded but still limited
• Pro user hitting 100/week limit
```

### Login Issues (25% of tickets)

**Password Problems**
```  
✅ Immediate Fixes:
• Use "Forgot Password" link
• Check spam folder for reset email
• Try typing password in notes app first
• Ensure caps lock is off

⚠️ Contact Support If:
• Reset emails not received (check spam first)
• Reset link says expired immediately  
• Account says "does not exist"
```

**Email Verification**
```
✅ Immediate Fixes:
• Check spam/junk folders thoroughly
• Wait 10 minutes for email delivery
• Try signing up with different email
• Whitelist LoadMaster emails

⚠️ Contact Support If:
• No verification email after 1 hour
• Verification link doesn't work
• Email shows already verified but can't login
```

### Calculation Issues (15% of tickets)

**RPM Seems Wrong**
```
✅ Check These Settings:
• Miles include deadhead distance
• Rate is total pay (not per-mile)
• Fuel price is current (Settings)
• Business setup complete (Pro users)

⚠️ Contact Support If:  
• Math doesn't add up manually
• Pro enhanced RPM missing
• Negative profit on profitable loads
```

## 🐛 Bug Reports

### How to Report Bugs Effectively

**Subject Line Format:**
```
BUG: Brief description (Browser/Device)
Example: "BUG: OCR fails on DAT screenshots (Chrome/iPhone)"
```

**Include This Information:**
- **Exact steps:** What you did before the bug
- **Expected result:** What should have happened
- **Actual result:** What actually happened  
- **Frequency:** Every time, sometimes, once
- **Workaround:** Any way you found to avoid it

### Screenshot Guidelines
- **Show the error:** Error messages, incorrect calculations
- **Show your input:** What you entered or uploaded
- **Show settings:** If calculation-related
- **Multiple angles:** Before/during/after if helpful

## ⚡ Debug Mode for Advanced Users

### Enable Debug Mode
1. **Add to URL:** `?debug=1` 
2. **Example:** `app.loadmastergpt.com/?debug=1`
3. **Reproduce issue** with debug active
4. **Screenshot debug panel** for support

### What Debug Mode Shows
- **OCR processing stages** and timing
- **API requests/responses** with details
- **Calculation breakdowns** step-by-step
- **Error stack traces** for developers
- **Performance metrics** for slow operations

### When to Use Debug Mode
- **OCR accuracy problems** - Shows AI processing
- **Calculation errors** - Reveals step-by-step math  
- **Performance issues** - Timing information
- **Intermittent problems** - Captures rare errors

## 💳 Billing & Account Issues

### Payment Failed
1. **Check card expiration** - Most common cause
2. **Verify billing address** - Must match card
3. **Contact bank** - Some block subscription services
4. **Try different card** - Backup payment method

### Subscription Not Active
1. **Check email** - Stripe sends confirmations
2. **Verify in app** - Upload counter shows 100/week  
3. **Wait 10 minutes** - Processing delays possible
4. **Contact billing** - Manual activation if needed

### Cancellation Process
1. **Account Settings** → Billing
2. **Cancel Subscription** button
3. **Keeps working** until period ends
4. **No partial refunds** after 7 days

## 💡 Pro Tips for Faster Support

### Write Better Support Emails
- **Specific subject lines** - "OCR fails on DAT screenshots"
- **One issue per email** - Don't combine multiple problems  
- **Include screenshots** - Show the problem visually
- **Mention Pro status** - Get priority treatment
