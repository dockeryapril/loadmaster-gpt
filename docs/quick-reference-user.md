## 📸 OCR Upload (Recommended)

### ✅ Best Results Tips
- **📱 Good lighting** - Natural light works best
- **✂️ Crop to load info** - Remove extra content  
- **📐 Hold steady** - Avoid blurry images
- **💾 Supported:** JPG, PNG, WebP

### 📊 Monthly Limits
- **Free:** 5 scans/month (resets 1st of month)
- **Pro:** 100 uploads/week (resets Sundays)
- **Manual:** Unlimited for all users

### 🔧 If OCR is Wrong
1. Click **Edit** on incorrect field
2. Update value manually
3. Calculations auto-update
4. App learns from corrections

---

## 📝 Manual Entry (Always Available)

### Required Fields
- **📍 Origin City:** Pickup location
- **📍 Destination City:** Delivery location
- **🛣️ Miles:** Total distance (include deadhead)
- **💰 Rate:** Total pay for load

### Optional But Helpful
- **⛽ FSC:** Fuel surcharge amount
- **⚖️ Weight:** Load weight in pounds
- **📋 Load #:** Reference number
- **💰 Extras:** Detention, lumper, etc.

## 🔧 Quick Troubleshooting

### OCR Not Working?
1. **Check uploads left** - See counter on dashboard
2. **Try manual entry** - Always unlimited
3. **Improve image quality** - Better lighting, crop tight
4. **Different format** - Try PNG if JPG fails

### Can't Sign In?
1. **Check email** - Typos are common
2. **Reset password** - Use "Forgot Password"
3. **Check spam** - Verification emails get filtered
4. **Clear browser** - Cache and cookies

### Calculations Look Wrong?
1. **Check miles** - Include deadhead distance
2. **Update fuel price** - Keep current in settings  
3. **Review business setup** - Revenue split affects Pro RPM
4. **Verify rate** - Total pay, not per-mile rate
