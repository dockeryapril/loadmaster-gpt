## 🚛 Equipment Type Selection

### Cargo Van
- **Capacity:** Up to 2,500 lbs
- **Good RPM:** $2.00+/mile
- **Fuel MPG:** 12-18 typical
- **Weekly Costs:** $400-800
- **Best For:** Expedited, small freight

### Straight Truck  
- **Capacity:** 10,000-26,000 lbs
- **Good RPM:** $2.50+/mile
- **Fuel MPG:** 8-12 typical  
- **Weekly Costs:** $800-1,500
- **Best For:** LTL, dock-to-dock

### Hotshot
- **Capacity:** 15,000-26,000 lbs
- **Good RPM:** $3.00+/mile
- **Fuel MPG:** 10-15 typical
- **Weekly Costs:** $1,000-2,000
- **Best For:** Oilfield, construction

```
Revenue Split: 80%

### 70/30 Split (Full Service)
```  
Revenue Split: 70%

Company Provides: Everything except fuel

## 🔧 Common Setup Mistakes

### ❌ Underestimating Costs
- **Problem:** Missing maintenance, permits, etc.
- **Fix:** Use comprehensive cost checklist
- **Impact:** Overestimating load profitability

### ❌ Wrong MPG Numbers
- **Problem:** Using manufacturer specs vs real-world
- **Fix:** Track actual fuel usage for 2 weeks
- **Impact:** Inaccurate fuel cost calculations

### ❌ Unrealistic Thresholds  
- **Problem:** Setting thresholds too high for market
- **Fix:** Research regional rates, start conservative
- **Impact:** Rejecting profitable loads

### ❌ Not Updating Settings
- **Problem:** Old fuel prices, outdated costs
- **Fix:** Monthly review and updates
- **Impact:** Increasingly inaccurate calculations
